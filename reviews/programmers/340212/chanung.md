# [PCCP 기출문제] 2번 / 퍼즐 게임 챌린지 (programmers/340212) — chanung

## 접근

레벨을 1부터 시작해 1씩 올려가며, 각 레벨에서 전체 퍼즐을 순회해 걸리는 시간이 `limit` 이하가 되는 첫 레벨을 찾는다. 시간 계산 공식(`(time_cur + time_prev) * (diff - level) + time_cur`)은 정확히 문제 정의대로 옮겼다.

## 개선점

### 1. (중요) 레벨을 1씩 선형으로 올리는 탐색 — time-complexity

레벨이 올라갈수록 총 소요시간이 단조 감소하므로 이분 탐색이 가능한 문제인데(같은 문제의 junsoo 풀이가 이 방식), 이 코드는 레벨 후보를 1씩 순차 증가시키며 매번 전체 배열을 O(N) 훑는다. 문제 제약상 `diffs` 최댓값이 100,000까지 가므로 최악의 경우 레벨 탐색 자체가 최대 10만 번 반복될 수 있고, 그때마다 N(최대 300,000)짜리 배열을 순회한다.

**실제로 돌려본 성능**: N=300,000, `diffs` 최댓값 근처로 무작위 생성, `limit=1`(레벨을 최대한 밀어붙이는 최악 조건)로 직접 실행했더니 **15초 안에 끝나지 않았다**(타임아웃으로 강제 종료). 같은 조건에서 junsoo의 이분 탐색 버전은 18ms.

## 복잡도

- 시간: `O(N * max(diffs))` — 최악의 경우 레벨 탐색 범위 × 매 레벨마다 전체 순회.
- 공간: `O(1)`

## 요약

시간 계산 공식과 로직 자체는 정확하다(작은 예제 전부 통과). 다만 레벨을 찾는 방식이 선형 탐색이라 제약 최댓값에서 확실하게 시간 초과가 난다. 단조성을 이분 탐색으로 바꾸면 해결된다.
