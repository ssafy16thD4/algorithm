# 풍선 사격 게임 (ssafy/balloon-shooting) — chanung

> 커밋 `d3ca0ae`(코드 개선본) 기준이다. 직전 `5f7c378` 대비 바뀐 것은 `depth >= n` → `depth == n`,
> `vis[i] = true` 위치, 네 갈래를 `else if` 로 묶은 것뿐이라 **동작은 같다**(600건 재대조 확인).

## 접근

터뜨릴 순서를 순열로 전부 만들어보는 백트래킹이다. `vis[]` 로 터진 풍선을 표시하고, 매번
왼쪽·오른쪽으로 훑어 **아직 안 터진 가장 가까운 풍선**을 찾아 점수 규칙 네 가지를 그대로 분기한다.

파일 맨 위 주석에 "좌우 모두 있으면 곱, 하나면 그 값, 없으면 자기 값" 세 규칙을 먼저 적어두고
코드가 그 순서 그대로 내려가는 게 좋다. 점수 규칙을 잘못 읽어서 틀리는 문제인데 여기서는 안 틀렸다.

**정확성은 확인했다.** 이미 정답으로 확인된 `김준수/week6/풍선 사격 게임.java`(이중 연결 리스트 버전)와
구간 DP 레퍼런스, 이 코드 셋을 무작위 600건(N ≤ 8)에 돌려 **불일치 0건**이다.

## 개선점

### 1. (중요) `O(N!)` 순열 전탐색 — N 이 조금만 커져도 못 푼다 — <time-complexity>

풍선을 터뜨리는 **순서**를 전부 만들기 때문에 `depth` 마다 남은 풍선을 전부 시도한다.
실측: `N=11` 한 케이스에 **1.43초**(JVM 기동 제외). N=13이면 100초를 넘는다.

이 문제는 순서를 고를 필요가 없다. **"이 구간에서 마지막에 터질 풍선"** 을 정하면
그 풍선이 터질 때의 좌우 이웃이 구간 양 끝으로 고정되므로, 구간 DP 로 `O(N³)` 이 된다.

```java
// v[0] = v[n+1] = 1 로 양끝을 패딩한다 (한쪽만 있을 때 곱이 그 값 그대로가 되도록)
// dp[l][r] = l 과 r 을 남긴 채 그 사이를 전부 터뜨렸을 때의 최대 점수
for (int len = 2; len <= n + 1; len++)
    for (int l = 0; l + len <= n + 1; l++) {
        int r = l + len; long best = 0;
        for (int k = l + 1; k < r; k++) best = Math.max(best, dp[l][k] + dp[k][r]);
        dp[l][r] = best + v[l] * v[r];   // k 가 마지막이면 이웃은 항상 l, r
    }
// 전체에서 "제일 마지막에 터지는 풍선" k 만 자기 값을 점수로 받는다
long ans = 0;
for (int k = 1; k <= n; k++) ans = Math.max(ans, dp[0][k] + dp[k][n + 1] + v[k]);
```

**실제로 돌려서 확인했다.** 위 DP 를 이 코드·김준수 코드와 무작위 600건 대조해 불일치 0건이고,
`N=200` 이 **0.02초**(JVM 기동 제외)다. `N=11` 1.43초 → 사실상 0초.

### 2. (사소) 이웃을 매번 처음부터 훑어서 같은 `O(N!)` 안에서도 N 배 느리다 — <redundant-loop>

`dfs` 한 노드마다 좌우 스캔이 각각 최대 `O(N)` 이라 전체가 `O(N! · N²)` 이다.
같은 순열 전탐색인 김준수 풀이는 이중 연결 리스트로 이웃을 `O(1)` 에 찾아 `O(N! · N)` 이고,
같은 `N=11` 에서 **0.91초 vs 1.43초**로 실제로 갈렸다.

1번(구간 DP)으로 가면 이 항목은 없어진다. 순열 전탐색을 유지할 거라면 `prev[]`/`next[]` 두 배열로
터진 풍선을 건너뛰게 이어붙이면 된다.

## 복잡도

- 시간: `O(T · N! · N²)` — 순열 전탐색이 지배적이고, 매 단계 이웃 선형 탐색이 `N` 배를 더 얹는다
- 공간: `O(N)` — `arr`, `vis` 와 재귀 깊이 `N`

## 요약

점수 규칙 네 갈래를 정확히 옮겨서 답 자체는 맞다(무작위 600건 0건 불일치). 문제는 복잡도 하나뿐인데,
그게 `O(N!)` 이라 N 이 조금만 커지면 못 푼다. "마지막에 터질 풍선"을 기준으로 잡는 구간 DP 로 바꾸면
`O(N³)` 이 되고, 검증까지 마친 코드가 위에 있다.
