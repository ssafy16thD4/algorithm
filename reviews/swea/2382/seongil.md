# 미생물 격리 (swea/2382) — seongil

## 접근

군집을 객체로 들지 않고 **격자 위 4개 평면(`board[값|시간|경쟁최댓값|방향][N][N]`)** 으로 들고,
좌표만 담은 덱을 돌리면서 한 시간씩 전진시킨다. 매 초 `newBoard` 를 새로 만들어 거기에 결과를 쓰므로
같은 초 안에서 이동 결과가 서로 간섭하지 않는다 — 동시 이동을 순차 코드로 옮길 때 가장 자주 틀리는
지점인데, 판을 통째로 갈아끼우는 것으로 그 문제를 아예 없앴다.

합체 규칙 처리가 이 풀이의 핵심이다. `board[2]` 에 **"이 칸에 도착한 개별 군집 중 최댓값"** 을 따로
들고 있어서, 3개 이상이 한 칸에 모여도 특별 케이스가 생기지 않는다.

```java
if (visited[nx][ny]) {
    newBoard[0][nx][ny] += currVal;                 // 수는 더하고
    if (newBoard[2][nx][ny] < currVal) {            // 방향은 개별 최댓값을 따른다
        newBoard[2][nx][ny] = currVal;
        newBoard[3][nx][ny] = d;
    }
}
```

`newBoard[0]`(누적합)이 아니라 `newBoard[2]`(개별 최댓값)와 비교하는 게 맞다. 누적합과 비교하면
두 번째 이후 군집이 절대 이기지 못해서 방향이 틀어진다.

**정확성은 확인했다.** 정석 순서(전원 이동 → 가장자리 도착 시 개별 절반·방향반전 → 같은 칸 합체)로 짠
레퍼런스와 무작위 대조해, 방향 동점이 없는 **2,369건 전부 일치**했다
(N=5~10 968건 + 가장자리 충돌이 잦도록 판을 5~6으로 좁힌 1,401건. 동점 131건은 문제 정의가
모호한 구간이라 제외 — `reviews/swea/2382/junsoo.md` 2번 항목과 같은 기준).

### 검토했지만 문제가 아니었던 것

가장자리 칸은 **먼저 도착한 군집만** 절반이 되고(`isPoison` 분기), 뒤이어 같은 칸에 도착하는 군집은
`visited` 분기로 넘어가 절반 처리 없이 전량이 더해진다. 순서에 따라 답이 갈리는 구조로 보였는데,
**실제로는 그 상황이 생기지 않는다.** 가장자리 칸에 도착한 군집은 즉시 방향이 반대로 바뀌어 다음 초에
안쪽으로 들어가므로, 가장자리를 따라 옆으로 움직이는 군집이 없다. 즉 가장자리 칸은 안쪽 이웃 한 곳에서만
도달 가능하고, 한 초에 두 군집이 같은 가장자리 칸에 모이는 일이 없다 (모서리 칸은 아예 점유되지 않는다).
위 2,369건 대조에서도 갈린 사례가 없었다.

## 개선점

### 1. (사소) 매 초 `4·N²` 정수 판을 새로 할당한다 — <space-complexity>

`board = new int[4][N][N]` 과 `visited = new boolean[N][N]` 이 **초마다** 새로 생긴다.
최대 입력(`N=100, M=1000`)이면 테스트케이스 하나에 `1000 × 5만` 칸, 50케이스면 25억 칸 분량의
할당·GC 가 발생한다. 군집 수 `K` 와 무관하게 드는 고정 비용이라, 군집이 다 죽은 뒤에도 계속 든다.

**실측**: `N=100, M=1000, K=1000` 50케이스에서 이 코드 **1.24초**, 같은 조건 레퍼런스(군집 리스트만
들고 격자를 안 만드는 쪽) **0.74초**. 3초 제한 안이라 통과에는 지장이 없어 `사소` 로 둔다.

줄이려면 판 두 벌을 미리 잡아두고 매 초 `swap` 하면서 **닿은 칸만** 되돌리면 된다.
`board[1]`(시간)은 어디서도 읽지 않으므로 평면을 3개로 줄여도 된다.

## 복잡도

- 시간: `O(T · M · (K + N²))` — 덱 순회는 `O(K)` 인데 초마다 판을 새로 만드는 `O(N²)` 이 같이 붙는다
- 공간: `O(N² + K)` — 4평면 격자 + 좌표 덱

## 요약

동시 이동을 판 교체로, 다중 합체의 방향 결정을 "개별 최댓값" 평면 하나로 눌러서 특별 케이스 없이 끝냈다.
정석 레퍼런스와 2,369건 대조에서 불일치 0건이고, 최대 입력 실측도 1.24초로 여유가 있다.
남은 건 초마다 격자를 새로 할당하는 고정 비용뿐이라 지금 상태로 제출해도 된다.
