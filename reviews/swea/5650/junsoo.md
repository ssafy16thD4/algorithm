# 핀볼 게임 (swea/5650) — junsoo

## 접근

빈 칸마다 네 방향으로 공을 굴려보고 최댓값을 취한다. 블록 반사를 `block[블록번호][방향]` 테이블 한 장으로 정리하고, 벽은 `block[5]`(정반대로 튕김)를 재사용한 것이 깔끔하다. 웜홀 좌표를 입력 파싱 중에 `wormholePos[번호][0..1]` 로 미리 저장해두는 것도 좋다.

블록에 부딪혔을 때 **위치는 그대로 두고 방향만 바꾸는** 처리도 맞다 — 공은 블록 칸으로 들어가지 않고 튕겨 나온다.

## 개선점

### 1. (치명) 파일 끝에 한글 자모 `ㅊ` 하나가 붙어 있어 컴파일이 안 된다 — `logic-edge-case`

```
error: reached end of file while parsing
}ㅊ
 ^
```

마지막 `}` 뒤에 `ㅊ`(U+314A)가 실수로 입력되어 있다. 한글 자모는 Java에서 식별자 시작 문자로 인정되기 때문에, 컴파일러가 새 타입 선언이 시작되는 줄 알고 읽다가 파일 끝을 만나 이 메시지를 낸다. 중괄호는 28:28로 정확히 맞는다(확인함).

**그 한 글자만 지우면 경고 없이 컴파일된다** — 실제로 지우고 `javac` 를 돌려 확인했다. 다른 문법 오류는 없다.

### 2. (치명) 시뮬레이션이 끝나지 않고, 안전 상한값을 그대로 점수로 반환한다 — `wrong-algorithm`

```java
int limit = N * N * 4 + 10;
for (int step = 0; step < limit; step++) { ... }
return score;   // limit 을 다 쓰고 빠져나와도 여기로 온다
```

루프가 `limit` 까지 돌고 그냥 빠져나오면, 그때까지 누적된 `score` 가 **정상적으로 끝난 게임의 점수인 것처럼** 반환된다. 공이 순환에 빠졌다는 사실이 호출자에게 전달되지 않는다.

**실제로 돌려본 반례** (위 `ㅊ` 를 지운 상태로 실행):

```
1
4
1 2 5 0
5 4 0 3
3 1 4 2
0 2 4 0
```

- 이 코드 출력: `#1 74`
- 이성일 코드 출력: `#1 5`

`74` 라는 값이 곧 증거다. `N=4` 일 때 `limit = 4*4*4 + 10 = 74` 이고, 출력이 **정확히 그 상한과 같다.** 즉 어떤 시작점에서 공이 한 번도 종료 조건(시작점 복귀·블랙홀)에 걸리지 않고 `limit` 번 전부 튕기며 매번 `score++` 한 것이다. 4×4 판에서 (위치, 방향) 상태는 `16 × 4 = 64`가지뿐이라 **중복 없는 궤적이 74번 튕기는 것은 불가능하다** — 순환이 확정이다.

원인은 반사 테이블 `block[1..4]` 쪽일 가능성이 높다. 공이 두 블록 사이를 오가는 궤적에 갇히면 위치가 갱신되지 않아 시작점 복귀 검사(`if (x == sx && y == sy)`)에 영원히 걸리지 않는다.

**고칠 방향** — 상한에 걸리는 것을 "정상 종료"와 구분해야 한다. `(위치, 방향)` 상태 방문 배열을 두고 같은 상태를 다시 만나면 순환으로 판정하는 편이 상한값보다 정확하다:

```java
boolean[][][] seen = new boolean[N][N][4];
...
if (seen[x][y][dir]) return score;   // 순환 — 더 굴려도 점수가 늘지 않는다
seen[x][y][dir] = true;
```

다만 **반사 테이블 자체를 먼저 검산하는 게 순서**다. 순환이 생긴다는 건 테이블이 문제 그림과 어긋났다는 신호이고, 순환 처리만 덧붙이면 틀린 점수를 조용히 반환하게 된다.

### 3. (사소) 파일명이 `public class SWEA5650` 과 다르다 — `naming`

`핀볼 게임.java` 안에 `public class SWEA5650` 이 있어, `ㅊ` 를 지운 뒤에도 파일명을 맞추거나 `public` 을 떼야 컴파일된다. 팀 규칙상 풀이 파일명은 건드리지 않으므로 제출 시점에만 맞추면 된다.

## 복잡도

- 시간: `O(N^4)` — 시작점 `N^2` × 방향 4 × 궤적 길이 `O(N^2)`.
- 공간: `O(N^2)` — `board` + 웜홀 좌표 테이블.

## 요약

반사를 테이블 한 장으로 정리하고 벽을 5번 블록으로 재사용한 구성은 좋다. 하지만 `ㅊ` 한 글자 때문에 컴파일이 막혀 있고, 그걸 지우고 돌려보면 시뮬레이션이 순환에 빠져 **자기 안전 상한값 74를 그대로 점수로 뱉는다.** 상한은 버그를 감추는 장치이지 종료 조건이 아니다 — 반사 테이블을 문제 그림과 하나씩 대조해 검산하는 것이 먼저다.
