## 개선점

### 1. (수정 완료 / 치명) `backward()` 가 단 한 번도 실행되지 않았다 — <uninitialized-state>

```java
while (nx != x && ny != y) { ... }   // 전
while (nx != x || ny != y) { ... }   // 후
```

전선은 한 축으로만 뻗으므로 `&&` 조건은 처음부터 false 였고, 칠한 `visited` 가 영원히 남아
형제 가지가 앞 가지의 전선 위에서 탐색했다. 9/9 대조에서 조밀 배치 1,500건 중 947건이 틀렸던 원인이다.

### 2. (수정 완료 / 치명) 전선을 끝까지 깐 분기의 복구 시작점이 판 밖이었다 — <logic-edge-case>

`while (isInRange(...))` 를 빠져나온 좌표는 판 밖이다. 1번만 고치면 `ArrayIndexOutOfBoundsException` 이
났다. 지금은 `nx -= dx[i]; ny -= dy[i];` 로 한 칸 되돌린 뒤 `backward` 를 부른다.

### 3. (수정 완료 / 치명) 답 앞에 디버그 출력이 나갔다 — <logic-edge-case>

`cell:` 줄과 `visited` 격자 출력이 실행되는 코드로 남아 표준출력을 오염시켰다. 지워졌다.

## 복잡도

- 시간: `O(T · 5^C · N)` — 코어 `C` 개마다 4방향 + 포기, 방향마다 전선 깔기가 `O(N)`.
  개수 기준 가지치기로 실제로는 훨씬 적게 돈다(최악형 50건 149ms). `C ≤ 12` 에서 충분하다.
- 공간: `O(N² + C)` — `maxinos` · `visited` 격자와 재귀 깊이

## 요약

붙였다. 레퍼런스와 3,050건 대조에서 전부 정답이고 최악형 입력도 빠르다.
